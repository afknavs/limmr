01 / Install and first launch

What Limmr is.

One place for context

People, circle briefs and ongoing tasks can be shared across permitted AIs, so each conversation does not have to start from scratch. All screens in this document use invented sample data.

Underneath

The window is a native Mac app written in SwiftUI. A small background program, called the engine, handles the WhatsApp link and checks each AI’s access; Go is used for that program because it can use the maintained WhatsApp multi-device library.

01 / Install and first launch

Allow the background helper.

Wait for a real state

A helper that is still starting is different from an empty account. If registration fails, use the offered retry or recovery route rather than repeating WhatsApp linking.

Underneath

macOS manages the engine as a background job. It can keep the connection and waiting tasks running when you close the main window; the app shows a starting or recovery state while the helper becomes ready.

02 / Link WhatsApp

Scan from Linked devices.

Use the current code

Keep the phone online and use the newest QR if it refreshes. Linking gives this Mac access to the history WhatsApp makes available; it does not give every AI access to that history.

Underneath

The engine receives a short-lived pairing code and the app draws the QR on your Mac. It uses an unofficial WhatsApp multi-device library, not the official business API, and stores the resulting device keys locally.

07 / Connecting your AIs

Choose the AI you use.

Own AI or given AI

Your own AI has full context access, including older chats, and can help set up circles and briefs. “An AI you were given” starts read-only and lets you choose circles and an end date; sending still follows circle rules and its separate permission.

Underneath

Each connection gets its own identity, access choices and Activity history. A local client on this Mac uses its own credential; a hosted client such as ChatGPT needs the optional secure remote connection.

Match the code

ChatGPT’s connection opens an authorisation page with a six-digit code. Return to Limmr to match and review it; client menu labels and account availability may differ from this sample guide.

08 / Asking from an AI

What a lookup brings back.

An illustrated lookup

A result might include a circle brief, the people involved, an unresolved request and references to the messages behind it. The AI uses those returned facts to answer you; excluded chats and counts must stay invisible, and the read appears in Activity.

Underneath

MCP is the common tool connection that lets different AIs ask Limmr for context. After identifying itself with whoami, an AI can find visible people or chats, read relevant messages and briefs, and receive evidence references and open work rather than the whole account.

09 / Approving a send

Check the exact message.

Know what confirmation means

An own-preset AI may use your explicit instruction to authorise a send where allowed, but it cannot override Never. The engine cannot prove that a human clicked an AI client’s Allow button; check send status rather than retrying an uncertain delivery.

Underneath

Circle rules can allow a send, require confirmation or forbid it; the strictest rule wins when circles overlap. Confirmation normally uses a separate draft step in the AI chat, while requested Mac review and background work can wait here on Home.

12 / Privacy controls

Choose each AI’s circles.

Ending access has a limit

Expiry and revocation stop future requests. They cannot erase data already copied into an AI conversation or retained by its provider, even though Limmr’s own stores remain on this Mac.

Underneath

The engine checks identity, capabilities, chat selection, circle access, hidden chats and expiry together on each call. A chat shared by Work and Family can still be visible through Work; read access never enables sending on its own.

12 / Privacy controls

Hide conversations from every AI.

What stays on this Mac

Limmr stores history, device keys, people and permissions locally; it does not claim those databases are encrypted at rest. A cloud AI still receives the permitted information returned to it, so hide or narrow context before sharing it.

Underneath

The global hidden list takes priority over each AI’s access. Hiding a direct chat does not erase its person or hide that person’s messages in a visible group; the boundary applies to the conversation.

14 / Updates

Review an update before restarting.

Keep work safe

An update should wait for active sends rather than interrupting them. After restart, check that the expected version and connection are ready; a polished sample screen alone is not evidence of a successful real update.

Underneath

Before replacing the engine, the updater blocks new sends and waits for active work to finish. It checks the expected replacement version, rolls back on failure and attempts to resume; a timed pause also expires so a failed update cannot leave sending stopped forever.
