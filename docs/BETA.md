# Welcome to the Limmr beta

Download the Mac DMG from [Releases](https://github.com/afknavs/limmr/releases) and follow the [setup guide](SETUP.md). Start with the demo to explore invented people and chats before linking WhatsApp or connecting an AI.

## Install and explore

1. Check the release version and supplied checksum, then drag Limmr to Applications.
2. The beta is ad-hoc signed and not notarized. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** for the first launch. Keep system protections enabled.
3. Try Home, task suggestions and Undo, People/Groups navigation, profile photos, task workspaces and Activity. Try light, dark and Increase Contrast.
4. When ready, link your WhatsApp and connect an AI. Review its circles, capabilities and expiry before letting it read. Linking, Contacts access, migration and dot pairing are separate choices.

## Things to know

- While paired, only the automation lease holder runs reminders and check-ins. Initially this is your Mac; your dot never takes over on its own.
- Hidden chats and AI permissions are separate on each engine. Synced people details and photos follow the receiving engine's permissions.
- Use JPEG or PNG for profile photos on Linux. Mac imports normalize photos to JPEG.
- Limmr uses an unofficial WhatsApp library; compatibility can change and there is account risk.

For Linux setup and scheduling, see [Run Limmr on Linux or a dot](handoffs/DOT-ENGINE.md).

## Send feedback

Open an [issue](https://github.com/afknavs/limmr/issues) with your app and OS versions, reproducible steps, expected behavior and actual behavior. Use invented data and demo-only screenshots. Keep real chats, contacts, databases, session files, QR/pairing codes, tokens and client configuration private.

Report security issues through [GitHub private vulnerability reporting](https://github.com/afknavs/limmr/security/advisories/new), with affected version, reproduction using invented data and impact.
